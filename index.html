Backup & Restore
Export your data regularly — required for multi-device sync
⚠️ Important — Read Before Proceeding
Why data must be exported regularly: This system stores all data in your browser's local storage — it only exists on the device and browser you are currently using.
Risk: Clearing browser cache, reinstalling the browser, or switching devices will permanently erase all data.
Solution: Export a backup after every significant update and share it with the team via WhatsApp, Email or Google Drive.
📤 Export Backup
Download all project data, seams, inspection records, users and logs as a .json file. Save it somewhere safe — Google Drive, email, or WhatsApp to the team.
📥 Import / Restore
Load a previously exported .json backup file to restore data on this device. This will replace all current data on this device.
⚠️ Current unsaved data will be overwritten. Export first if needed.
📱 How to Sync Across Devices
${[ ['1️⃣','Export Backup','Admin opens TQIMS → Backup & Restore → Download Backup File'], ['2️⃣','Share the File','Send the .json file via WhatsApp, Email, or Google Drive to team members'], ['3️⃣','Others Import','Each member opens TQIMS → Backup & Restore → Select Backup File → Import'], ['4️⃣','Repeat Regularly','After every update (new seams, inspections), Admin exports and re-shares'], ].map(([n,t,d])=>`
${n}

`).join('')}
