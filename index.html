Backup & Restore
Export regularly — JSON for full restore, Excel for historical data import
⚠️ Important: Data is stored in this browser only. Clearing cache or switching devices erases it. Export a backup after every significant update and save to Google Drive / WhatsApp / Email.
📤 Export Full Backup (JSON)
Downloads everything — all projects, seams, users, logs. Use to restore to any device.
📥 Restore from JSON
Load a previously exported JSON file. Replaces ALL current data.
⚠️ Export first if needed — current data will be overwritten.
📊 Excel — Export & Historical Data Import
Export to Excel: Downloads every seam with all its stages as a spreadsheet. Open in Excel or Google Sheets, fill in the Status column for previous work, then import.
Import from Excel: Bulk-update stage statuses from your filled spreadsheet. Use a custom past timestamp so historical records appear with the correct dates — without going through the live offer/inspect flow.
① Export Template
Opens in Excel. Fill Status column with: accepted, rejected, returned, or leave blank to skip. Save as .csv then import below.
② Import Filled Excel / CSV
Select your filled CSV file. New seams in the file will be created automatically. Existing seams will have their stages updated. Data becomes visible to all users immediately after import.
